# Data layer

## Stack

- SQLModel on SQLAlchemy 2 async, driven by `asyncpg` in production and `aiosqlite` in tests.
- `Database` (in `lib/db/session.py`) holds `engine` and
  `session_factory = async_sessionmaker(engine, class_=AsyncSession, expire_on_commit=False)`.
- Sessions:
  - Requests get **one session each** via `SessionDep`.
  - Workers and background tasks open their own with
    `async with db.session_factory() as session:`.

## Tables

- **Model class:** singular PascalCase. **`__tablename__`:** plural snake_case, always explicit
  (`Invoice` → `"invoices"`, `ApiCredential` → `"api_credentials"`).
- **Base classes** (`lib/db/base.py`):
  - `TimestampMixin` provides `created_at`, `updated_at`, `patchable`, `validate_patch()` and
    `patch()`.
  - `BaseModel(TimestampMixin)` adds `id: uuid.UUID` as the primary key, generated by
    `uuid.uuid4`.
- **Constraint and index names are explicit:** `uq_<table>_<cols>` and `ix_<table>_<cols>`.
  Partial unique indexes use `postgresql_where=`.
- **Enums** are stored by value with `sa_type=stored_by_value(MyEnum)`, never as a native
  Postgres enum. Adding a member then needs no migration.
- **JSON columns** use `sa_type=JSON` with a typed default factory.

## Ids

- Primary keys are UUIDs by default.
- **Typed public ids (optional).** When ids are user-visible, keep the UUID in the database and
  prefix it on the wire with an `Annotated` type:
  ```python
  NoteId = Annotated[
      uuid.UUID,
      BeforeValidator(parse_prefixed("note")),
      PlainSerializer(lambda v: f"note_{v.hex}", return_type=str),
  ]
  """A note id: a UUID in the database, ``note_<hex>`` on the wire."""
  ```
  The parser accepts every historical form back, including a bare UUID.
- **Identity tables** (users, orgs) may use prefixed string keys such as `user_<hex>` and
  `org_<hex>`, built by `new_<entity>_id()`. The prefix is cosmetic and never parsed.

## Timestamps

- Every timestamp is `UTCDateTime`: aware UTC in Python, `timestamptz` in Postgres, `…Z` on the
  wire.
- Get the current time with `utcnow()`. **Never `datetime.now()` or `datetime.utcnow()`.**
- Name event times `<event>_at` and make them `UTCDateTime | None`.

## Repositories

- `BaseRepository[T]` provides `get`, `get_or_404(id, label)`, `list(offset, limit)`,
  `create`, `update` and `delete`.
- It also provides `encode_cursor(at, id)` and `decode_cursor(cursor)` as static methods.
- **Base writes commit and refresh.**
- Domain methods that are part of a larger unit use `session.add` / `flush` and say "The session
  is not committed."
- **Scoped reads take the scope first:** `get_for_org(org_id, note_id)`,
  `list_by_org(org_id)`. A row from another scope is `None`, exactly like a missing one.
- **Race-safe get-or-create:**
  ```python
  try:
      return await self.create(Note(org_id=org_id, display_name="Inbox"))
  except IntegrityError:
      await self.session.rollback()
      return await self.get_by_name(org_id, "Inbox")
  ```
- **Keyset page:**
  ```python
  async def list_page(self, org_id: str, *, cursor: str | None, limit: int) -> tuple[list[Note], str | None]:
      """List the organization's notes newest first, one page at a time."""
      stmt = select(Note).where(Note.org_id == org_id)
      if cursor:
          at, last_id = self.decode_cursor(cursor)
          stmt = stmt.where(or_(Note.created_at < at, and_(Note.created_at == at, Note.id < last_id)))
      stmt = stmt.order_by(Note.created_at.desc(), Note.id.desc()).limit(limit + 1)
      rows = list((await self.session.execute(stmt)).scalars().all())
      page = rows[:limit]
      next_cursor = self.encode_cursor(page[-1].created_at, page[-1].id) if len(rows) > limit else None
      return page, next_cursor
  ```

## Transactions

- **The service owns the commit** for a multi-row unit: `add` → `flush()` (to get ids) → more
  writes → `commit()`.
- Savepoints use `async with session.begin_nested():`. Row locks use `.with_for_update()`, in a
  `get_for_update_or_404`.
- **Persist first, then signal.** Commit the row before notifying a queue, worker or external
  system, and make the signal idempotent on retry.

## Migrations (Alembic)

- Each service has **one tree** under `migrations/` and owns its own database. Two services
  never share tables.
- **File name:** `NNNN_snake_slug.py`, a 4-digit sequence. **The revision id is the file stem**,
  not a hash:
  ```python
  revision: str = "0007_invoice_due_date"
  down_revision: Union[str, None] = "0006_invoices"
  ```
  Create one with `uv run alembic revision -m "invoice due date" --rev-id 0007_invoice_due_date`.
- `migrations/env.py`:
  - runs async;
  - reads the URL from the settings class directly, **never** from `alembic.ini` and never by
    importing `config.py`;
  - imports every model module for its side effect (`# noqa: F401`);
  - filters autogenerate to the tables this service owns (`include_object`);
  - takes `pg_advisory_xact_lock(<service key>)`, so concurrent boots serialize.
- `0001_baseline` creates the initial tables from the live models
  (`SQLModel.metadata.create_all(bind, tables=[...], checkfirst=True)`). Every later revision
  is **existence-guarded**, so it can re-run safely:
  ```python
  def upgrade() -> None:
      insp = sa.inspect(op.get_bind())
      if any(c["name"] == "due_at" for c in insp.get_columns("invoices")):
          return
      op.add_column("invoices", sa.Column("due_at", sa.DateTime(timezone=True), nullable=True))
  ```
- **The revision docstring says why** the change exists, and whether it is **rolling-safe**
  (old pods keep working against the new schema) or needs a **drain** deploy.
- Migrations run in the image entrypoint (`alembic upgrade head` with a retry loop), before the
  process starts. **Never call `create_all` at app startup.**
- Migration files are the one place where inline comments are allowed.
